# Foodgram

Сайт доступен по адресу: http://158.160.150.229/

Foodgram — веб-приложение для публикации рецептов. Пользователи могут
создавать и публиковать свои рецепты, подписываться на других авторов,
добавлять понравившиеся рецепты в избранное, а также формировать список
покупок: он автоматически суммирует количество нужных ингредиентов по всем
рецептам, добавленным в корзину, и позволяет скачать его в виде текстового
файла. Для каждого рецепта доступна короткая ссылка для быстрого доступа.

## Стек технологий

- **Backend:** Python, Django, Django REST Framework, Djoser (аутентификация
  по токену), PostgreSQL
- **Frontend:** React
- **Инфраструктура:** Docker, Docker Compose, Nginx, Gunicorn

## Запуск проекта

Находясь в папке `infra`, выполните команду `docker-compose up`. При
выполнении этой команды контейнер frontend, описанный в `docker-compose.yml`,
подготовит файлы, необходимые для работы фронтенд-приложения, а затем
прекратит свою работу.
